# WebApp React - TDD - Blog Personale

WebApp Sviluppata seguendo i principi del Test Driven Development

Blog Personale in cui è possibile creare Post, Visualizzarli, Cancellarli

I Post sono salvati in local Storage

Ogni componente è stato creato partendo dalla classe di test seguendo il ciclo: Red → Green → Refactor

App in sviluppo, verrà pubblicata appena completa
